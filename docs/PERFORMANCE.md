# Performance

The workflow parallelizes the three research perspectives and reference discovery. Research, synthesis, renders, and accepted placement retrieval are content-addressed. Playwright is reused across captures, while each view gets an isolated page.

A source correction invalidates every previous view pass because all required views must prove the same compiled revision. Limits on runtime, logical AI calls, source repairs, and QA target count bound cost and prevent endless loops.

The accepted library retrieves small placement records instead of prior source code, keeping prompts focused and avoiding identical-scene cloning.
